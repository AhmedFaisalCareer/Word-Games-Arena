# 🎮 Word Games Arena

> ⚡ A modern browser-based gaming arena featuring word games, trivia, strategy games, player profiles, and online multiplayer battles.

Word Games Arena is an interactive gaming platform built with **HTML, CSS, and JavaScript**. The project combines multiple mini-games into one modern interface and is designed to grow into a fully online multiplayer gaming platform.

---

## ✨ Features

### 🎯 Multiple Games

Word Games Arena includes a collection of different games:

- 🪢 Hangman
- 🔀 Word Scramble
- ⚡ Letter Rush
- 🧠 Word Master
- ❓ Trivia Blitz
- ⚔️ Player Duel
- ♟️ Chess
- 🎯 Daily Challenge

More games can be added in future updates.

---

## 👤 Player Profile

Each player can have their own profile containing:

- 👤 Username
- 😀 Avatar
- ⭐ XP
- 🪙 Coins
- 🏆 Wins
- ❌ Losses
- 🔥 Streak
- 📊 Best Scores
- 🎖️ Achievements
- 🎮 Game statistics

---

## 🎮 Game Modes

### 🤖 Single Player

Play different games against the built-in game system.

Features include:

- Score tracking
- Timers
- Levels
- XP rewards
- Coins
- Streaks
- Achievements

---

### ⚔️ Local Multiplayer

Play certain games with another player on the same device.

Players can compete against each other and track their scores.

---

### 🌐 Online Multiplayer

The project is designed to support real-time online battles.

Planned online features include:

- 👥 Online player accounts
- 🏠 Create a room
- 🔑 Room codes
- 🔗 Shareable battle links
- ⚔️ Real-time word battles
- ♟️ Online chess
- 🏆 Online results
- 📊 Online leaderboards
- 🔄 Rematches
